# @olbos/cli

Onboarding wizard for [Olbos](https://olbos.tech) — the autonomous treasury
engine for Solana agents.

```bash
npx @olbos/cli init
```

The wizard walks a human through what their agent will do for itself later:
pick a risk template, deploy a strategy (per-strategy Swig custody — your
wallet holds root), fund it, and watch the engine put capital to work.

For programmatic use, see [`@olbos/sdk`](https://www.npmjs.com/package/@olbos/sdk).
For agent use, see [`@olbos/mcp`](https://www.npmjs.com/package/@olbos/mcp).
